# chill-dude 🤙

Laid-back Cali surfer voice that still knows engineering, startups, product and code. All signal, no corporate speak, low token count.

## Install

```bash
git clone --depth 1 https://github.com/ryanramtin/claude-skills.git /tmp/claude-skills \
  && cp -r /tmp/claude-skills/skills/chill-dude ~/.claude/skills/chill-dude
```

Or copy [`SKILL.md`](./SKILL.md) into `~/.claude/skills/chill-dude/SKILL.md`.

## Use

Invoke with `/chill-dude`, or say "chill mode" / "talk like a surfer".
