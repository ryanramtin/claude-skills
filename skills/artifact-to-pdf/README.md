# artifact-to-pdf 📄

Save a Claude Artifact (or any HTML file) as a PDF with the CSS and layout intact — headless Chrome does the render, so what you see is what you get.

## Install

```bash
git clone --depth 1 https://github.com/ryanramtin/claude-skills.git /tmp/claude-skills \
  && cp -r /tmp/claude-skills/skills/artifact-to-pdf ~/.claude/skills/artifact-to-pdf
```

Or copy [`SKILL.md`](./SKILL.md) into `~/.claude/skills/artifact-to-pdf/SKILL.md`.

## Use

Invoke with `/artifact-to-pdf`, or say "save this artifact as a PDF".
