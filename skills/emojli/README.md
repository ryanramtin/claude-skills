# emojli 🧠⚡

Extreme clarity, minimal words, heavy but *logical* emoji usage. Emoji carry meaning (✅ done, ❌ blocked, ⚠️ risk, ⏭️ next) so replies scan in seconds instead of being read line by line.

## Install

```bash
git clone --depth 1 https://github.com/ryanramtin/claude-skills.git /tmp/claude-skills \
  && cp -r /tmp/claude-skills/skills/emojli ~/.claude/skills/emojli
```

Or copy [`SKILL.md`](./SKILL.md) into `~/.claude/skills/emojli/SKILL.md`.

## Use

Invoke with `/emojli`, or say "emoji mode" / "be terse with emojis".
