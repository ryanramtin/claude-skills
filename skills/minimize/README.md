# minimize 🌊

A short, scannable rundown of what's actually happening across your projects — what's hot, what landed, what's owed. Reads in about twenty seconds. Signal only: if it wouldn't change what you do next, it gets cut.

## Install

```bash
git clone --depth 1 https://github.com/ryanramtin/claude-skills.git /tmp/claude-skills \
  && cp -r /tmp/claude-skills/skills/minimize ~/.claude/skills/minimize
```

Or copy [`SKILL.md`](./SKILL.md) into `~/.claude/skills/minimize/SKILL.md`.

## Use

Invoke with `/minimize`, or say "catch me up" / "where are we" / "sitrep".
